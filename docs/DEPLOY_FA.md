# انتشار روی HTTPS (GitHub Pages)

Chrome اندروید فقط روی HTTPS به بلوتوث دسترسی می‌دهد. این اپ ایستا است و روی GitHub Pages با HTTPS خودکار منتشر می‌شود؛ داده‌ها در Firebase می‌مانند و با قوانین Firestore فقط برای حساب تو قابل دسترسی‌اند.

**مهم:** کد و صفحهٔ اپ روی GitHub Pages برای هر کسی که نشانی را داشته باشد باز می‌شود (داده‌ها نه). انتشار فقط با تأیید خودت انجام می‌شود.

## ۱. یک سازمان GitHub جدا برای همین اپ

هر PWA روی گوشی باید مبدأ جدا داشته باشد (اپ‌های «مدار»، «تن‌آرا» و «ویر» مبدأهای خودشان را دارند).

1. در github.com، از منوی پروفایل: **Your organizations → New organization → Free**.
2. نام پیشنهادی: `gan-smart-app` (یا هر نام آزاد). نشانی نهایی می‌شود `https://gan-smart-app.github.io/`.

ساخت سازمان با CLI ممکن نیست؛ پس از ساخت، بقیه را می‌توان با `gh` انجام داد.

## ۲. مخزن و Pages

1. مخزن `gan-smart-app.github.io` را در همان سازمان بساز و این پوشه را در شاخهٔ `main` به آن push کن.
2. در مخزن: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. در **Settings → Secrets and variables → Actions → Variables** این متغیرها را بساز (هیچ‌کدام secret نیستند):
   - `FIREBASE_API_KEY` و `FIREBASE_PROJECT_ID` از تنظیمات وب‌اپ Firebase.
   - `AI_ENDPOINT` فقط اگر هوشواره را راه انداختی؛ وگرنه نساز.
4. هر push به `main`، فایل `.github/workflows/pages.yml` آزمون‌ها را اجرا، اپ را می‌سازد و منتشر می‌کند.

## ۳. Firebase

- در **Authentication → Settings → Authorized domains**، دامنهٔ `gan-smart-app.github.io` را اضافه کن.
- قوانین `firestore.rules` را با UID خودت منتشر کن (جزئیات در FIREBASE_SETUP_FA.md).

## ۴. روی گوشی

1. نشانی HTTPS را مستقیم در Chrome اندروید باز کن (نه داخل پیام‌رسان).
2. از تنظیمات برنامه وارد حساب شو؛ رکوردهای مک ظاهر می‌شوند.
3. برای اتصال روبیک به گوشی، ابتدا اتصال آن را در مک قطع کن؛ یک روبیک هم‌زمان به دو دستگاه وصل نمی‌شود.
4. افزودن به صفحهٔ اصلی (نصب) اختیاری است؛ اپ بدون نصب هم کار می‌کند.

مجوز بلوتوث و IndexedDB به مبدأ وابسته‌اند: داده‌های `127.0.0.1:5180` روی مک خودکار به نشانی منتشرشده منتقل نمی‌شوند؛ اگر پیش از ورود به حساب روی نشانی محلی تمرین کرده‌ای، از تنظیمات خروجی JSON بگیر و روی نشانی جدید وارد کن.
