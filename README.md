# GAN SMART · فضای شخصی تمرین روبیک

وب‌اپ شخصی فارسی برای اتصال به روبیک هوشمند GAN، تمرین با تایمر و ثبت رکورد. این نسخه عمداً ساده است و قابلیت‌ها قدم‌به‌قدم اضافه می‌شوند؛ نسخهٔ کامل قبلی (یادگیری، درس‌ها، چالش‌ها، راهنمای حل، بازپخش، شبیه‌ساز، هوشواره) در شاخهٔ Git `full-v1` نگه داشته شده است. رابط از روی طراحی نهایی UX Pilot (۱۲ شیت دسکتاپ و ۹ شیت موبایل) ساخته شده است. کنترل GAN Robot در محدودهٔ این نسخه نیست.

## اجرا روی همین مک

Node.js 24 با Homebrew نصب شده است (`/opt/homebrew/opt/node@24/bin`).

```bash
npm install
```

```bash
npm run dev
```

نشانی: http://127.0.0.1:5180 (فقط روی همین مک). بلوتوث وب روی `localhost`/`127.0.0.1` در Chrome کار می‌کند؛ گوشی به نشانی HTTPS نیاز دارد (پایین).

## آزمون‌ها

```bash
npm run check
```

این فرمان اجرا می‌کند: آزمون‌های محصول (`npm test`)، آزمون‌های مرجع نسخهٔ ۱۵ (`npm run test:v15`)، تطبیق SHA-256 فایل‌های اتصال (`npm run verify:v15`) و ساخت نهایی.

## ساختار

| بخش | مسیر |
|---|---|
| اتصال نسخهٔ ۱۵ (بدون تغییر، هش‌شده) | `public/gan-v15/`، مرجع و آزمون‌ها در `vendor/gan-v15/` |
| سازگارکنندهٔ اتصال (تلاش‌ها، لغو، رخدادها، گزارش) | `src/core/connection.mjs` |
| موتور مکعب، حالت‌ها، حل‌گر | `src/core/cube.mjs`، `src/workers/solver.worker.js` (Kociemba/cubejs) |
| تمرین و تایمر | `src/core/practice.mjs` |
| آمار، ao5/ao12، +2/DNF | `src/core/stats.mjs` |
| ذخیرهٔ محلی، صف، همگام‌سازی، پشتیبان | `src/core/store.mjs`، `sync.mjs`، `auth.mjs`، `backup.mjs` |
| رابط | `src/screens/*`، `src/layout/Shell.jsx`، `src/components/*` |

## حساب، همگام‌سازی و انتشار

مثل اپ «ویر»: حساب و همگام‌سازی با **Firebase** (ورود ایمیل/گذرواژه + Firestore از طریق REST) و میزبانی ایستا روی **GitHub Pages** با یک نشانی جدا (یک سازمان GitHub مخصوص همین اپ، تا با PWAهای دیگر روی یک مبدأ قاطی نشود). هیچ سرور همیشه‌روشنی روی مک لازم نیست.

1. پروژهٔ Firebase: گام‌به‌گام در [docs/FIREBASE_SETUP_FA.md](docs/FIREBASE_SETUP_FA.md) (ثبت‌نام عمومی خاموش، فقط حساب خودت، قوانین `firestore.rules` فقط برای UID تو).
2. انتشار: [docs/DEPLOY_FA.md](docs/DEPLOY_FA.md).
3. تا پیش از این دو، اپ کامل کار می‌کند و داده در «ذخیرهٔ محلی» همان مرورگر است.

تمرین آفلاین در IndexedDB ذخیره و تغییرها در صف می‌مانند؛ با برگشت اینترنت همگام می‌شوند. هر رکورد شناسهٔ یکتا و نسخه دارد؛ نسخهٔ پذیرفته‌شدهٔ سرور مبنا می‌ماند و نسخهٔ محلی متعارض در «نیازمند رسیدگی» نگه داشته می‌شود؛ حذف‌ها برگشت‌پذیرند و با دستگاه قدیمی زنده نمی‌شوند.

## زمان‌گیری

زمان‌ها «زمان دریافت حرکت در مرورگر» هستند (مسیر Legacy با خواندن حدود هر ۵۰۰ میلی‌ثانیه). تایمر مسابقه‌ای نیست؛ حرکت‌های دسته‌ای زمان جدا ندارند و مکث یا زمان مرحله‌ها از این داده ساخته نمی‌شود.
